# Konsultan Kewangan Hafiz — Landing Page

## Files
- `index.html` — page content and structure
- `styles.css` — responsive navy / black / gold styling
- `script.js` — mobile menu and WhatsApp enquiry form
- `assets/hafiz-photo.jpg` — add your own portrait here

## Add your photo
1. Save your chosen portrait as `hafiz-photo.jpg`.
2. Put it inside the `assets` folder.
3. Keep the filename exactly `hafiz-photo.jpg`.

The page currently displays an initials placeholder if the photo is missing.

## Publish with GitHub Pages
1. Create a public repository named `KJTAN0819.github.io` (if that is your GitHub username).
2. Upload all files and the `assets` folder to the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.
4. Wait for the deployment and visit `https://KJTAN0819.github.io`.
